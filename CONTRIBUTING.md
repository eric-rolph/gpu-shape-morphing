# Contributing to GPU Font Engine

First off, thank you for considering contributing to the GPU Shape Morphing repo. It's people like you that make open-source a highly rewarding community!

### How Can I Contribute?

* **Geometry Parsing**: Integrate TrueType or OTF vector parsing to import letters directly!
* **UX/UI Improvements**: Provide more fluid slider feedback, animations, and accessible interactions.
* **Math Optimization**: Help speed up algebraic polynomial operations within `sdBezier` GLSL.

### Development Process

1. Fork the repository and create your feature branch: `git checkout -b my-new-feature`
2. Commit your logical updates referencing the mathematical reasoning.
3. Ensure no linting errors are active, obeying the indentation standards defined in `.editorconfig`.
4. Open a Pull Request detailing what graphics modifications you've enabled!
