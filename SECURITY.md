# Security Policy

## Supported Versions

Currently, the `master` repository branch receives all critical architectural, mathematical, and WebGL security updates. 

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| earlier | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues. 

Instead, report them via email to `ericrolph@example.com` or via GitHub Security Advisories. We will respond within 48 hours to acknowledge the report and provide an expected timeline for the patch.
